# Data Structures and Algorithms Portfolio

Welcome to my DSA portfolio! This repository contains my solutions to various algorithmic problems (mostly from LeetCode), implemented in **Python**.

The goal here is not just to grind problems, but to write clean, efficient, and well-documented code that demonstrates a deep understanding of core computer science concepts.

## 🚀 Workflow
1. Navigate to the relevant topic folder.
2. Create a new `.py` file for the problem (e.g., `two_sum.py`).
3. Include the problem description or a link to it at the top of the file as a docstring.
4. Write the solution, including time and space complexity in the comments.
